# 🃏 TCGカードショップシミュレーター

「アニモン（アニマルモンスター）」のトレーディングカードを売るカードショップを経営する、3Dの経営シミュレーションです。
パックを棚に並べて、レジを打って、自分でもパックを開けてレアカードを当てて、シングルカードを売って、お店を大きくしていきます。
ブラウザだけで動くので、GitHub Pages に置くだけでスマホ（横画面）でも PC でも遊べます。最大4人の協力プレイにも対応しています。

> 「TCG Card Shop Simulator」の遊び方と、ポケモンカードのレア度の見た目（ノーマル／ホロ／フルアート／レインボー／ゴールド）を参考にしたオリジナル作品です。公式作品・開発元とは関係ありません。
> お店の基盤は「マートメイツ」、カードに登場するキャラクターは「アニマルモンスター（アニモン）」のものを使っています。

### レア度と見た目（ポケカ風）

| レア度 | 見た目 | 封入率（1枚あたり） | 相場の目安 |
|---|---|---|---|
| **N**（ノーマル） | ふつうの枠。タイプ色の背景と景色の窓 | 69.8% | 5〜10円 |
| **R**（レア） | 絵の窓がホロ（虹色にキラキラ） | 17.35% | 15〜40円 |
| **SR**（スーパーレア） | フルアート。キャラがカード全体に、細かい斜めの凹凸ラインと銀のホロ | 7.6% | 80〜200円台 |
| **SSR**（スペシャルスーパーレア） | **色ちがいのアニモン**×星空のスペシャルアート。銀のグリッター | 4.0% | 300円〜1,000円台 |
| **HR**（ハイパーレア） | SSRをさらに **レインボー** 加工（キャラも背景も虹色） | 1.0% | 1,400〜4,800円 |
| **UR**（ウルトラレア） | SSRをさらに **ゴールド** 加工（金の枠・金色のキャラ・金のグリッター） | 0.25% | 5,000〜16,000円台 |
| ✨ **フラッシュ（箔付き）** | どのレア度にも付く。光の帯が流れて、キラキラと輝く（3Dの棚でも光る） | 各カード 5% | そのカードの **3倍** |

- 封入率は **1枚ごとの独立判定**。1パック5枚それぞれが上の確率で決まります（BOX保証はありません）。
- 1BOX（10パック＝50枚）に入る平均：UR 0.13枚・HR 0.5枚・SSR 2枚・SR 3.8枚・フラッシュ 2.5枚。
- **レアなカードほど高く売れます。** 相場は弾（あとの弾ほど高い）とキャラの人気でも変わり、毎日少しずつ動きます。高いカードを狙うお金持ちのコレクターもたまに来店します。

- 画面でカードにさわる（PCはマウスを動かす）と、カードが傾いて光の反射とホロが動きます。
- カードの絵は Canvas で描いています（`js/cardart.js`）。アニモンのイラストは「アニモン」の3Dモデルから撮影した画像（`img/mon/`）。

## 🧑‍💼 従業員（最大10人）

仕事は **🧾 レジ** と **📦 品出し** の2つ。**だれでも両方の仕事ができます** が、人によって **レジのはやさ** と **品出しのはやさ** がちがいます。
レジが得意で品出しが遅い人、品出しが得意でレジが遅い人、両方同じはやさの人がいます。
仕事は「🔄 両方（おまかせ）」「🧾 レジ係」「📦 品出し係」「🏷️ 値段係」から選べます。「両方」にすると、レジにお客さんが並んでいて誰もいなければ（両方の人の中でいちばんレジが早い人が）レジへ行き、空いたら品出しにもどります。

雇うには、お店のレベルが届いたあと、パソコンの「🧑‍💼従業員」（または「🔑ライセンス」→ 従業員）で **雇用ライセンス** を買います。日給は下の表のとおりです（前のバージョンの2倍）。

**🏷️ 値段係の仕事**
相場は毎日変わるので、値段係は棚とシングルカードの棚を歩いて回り、値段を **「ギリギリ売れる値段」（相場の+20%）** に直しつづけます。相場が上がれば値上げ、下がれば値下げ（高すぎて売れなくなるのを防ぐ）。値段係のはやさは、その人の品出しのはやさと同じです。

**品出しの仕事**（基本はスーパーマーケットシミュレーターと同じ）
1. 値札のついた棚の在庫が減っていたら、倉庫棚や店の前の段ボールから補充する
2. 発注して店の前に届いた段ボールを持って、**その商品のラベルが貼ってある倉庫棚の段** にしまう（ラベルのない商品は片付けない。頭の上に 🏷️❓ が出ます）
3. 空になった段ボールはゴミ箱へ

倉庫棚の段を狙って「ラベルを貼る」で商品を選べます（プレイヤーはどの段にも置けて、ラベルのない段に置くと自動でその商品のラベルが貼られます）。

## 🎮 操作

| | スマホ | PC |
|---|---|---|
| 移動 | 左のスティック | WASD / 矢印キー |
| 視点 | 画面右側をドラッグ | マウス（画面クリックでロック） |
| 行動（拾う・補充・手に持つ・棚に置く・シュッ・カードを置く） | 大きいボタン | E / 左クリック |
| 段ボールを開ける／閉じる・設備を動かす | 📦 ボタン | F |
| サブ行動（開封・回収・ラベル・5パック持つ） | 小さいボタン | Q / 右クリック |
| コレクションファイル | 画面上の 📒 | C |
| 建築モード | 🔨 | B |
| 視点切替 | 🎥 | V |
| 評判と口コミ | 画面上の ⭐ | Tab |
| チャット（ルームのみ） | 💬 | Enter |
| メニュー | ≡ | Esc |

**基本の流れ**：パソコン室（入口の右・倉庫から入る）のパソコンで、ライセンスを持っている商品を仕入れる → 店の前に届いた段ボールを持って「開ける」→ 棚を狙って「補充」→ 入口の看板を OPEN → レジでスキャン＆お会計 → 閉店して収支画面 →「次の日へ」。

**パック・BOXの開け方**
- 棚の枠や、開いた段ボールのパックを狙って「手に持つ」（Qで5パックまとめて）。手に持ったまま「🎴 パックを開封」（F で まとめて開封）。
- BOXは1つだけ手に持てます。「🎁 BOXを開封」で **10パック** が手に出てくるので、1パックずつ開けても、まとめて開けても、途中でやめて「棚に置く」で売り物にしてもOK。
- パックの段ボールを持ったまま「🎴 パックを開封」でも開けられます（BOXの段ボールなら、足元に置いてBOXを開けます）。
- 出たカードは📒コレクションファイルに入ります。カードの棚の枠を狙って「カードを置く」→ ファイルからタップで並べられます。

## 🚀 GitHub Pages で公開する

1. GitHub で新しいリポジトリ（例：`tcg-card-shop-simulator`）を **Public** で作成。
2. このフォルダの中身（`index.html` / `css` / `js` / `img` / `icons` / `README.md` など）を **フォルダごと** アップロードして Commit。
   - `index.html` がリポジトリの一番上にある状態にしてください。
3. **Settings → Pages** で **Source: Deploy from a branch**、**Branch: main / (root)** を選んで Save。
4. 1〜2分後に `https://あなたのユーザー名.github.io/リポジトリ名/` で遊べます。

ビルド不要の素の JavaScript（ES モジュール）です。three.js と Firebase は CDN から読み込みます。
ローカルで試すときは `python3 -m http.server` などでフォルダを配信して `http://localhost:8000` を開いてください（ファイルを直接開くと動きません）。

## 🔥 Firebase の設定（オンライン機能）

`js/firebase-config.js` には、このゲーム専用の Firebase プロジェクト **card-shop-d54b1** を設定してあります。
データはデータベースの **`tcg/` の下** に保存されます。

### はじめにやること（Firebase コンソール）
1. **Authentication → Sign-in method → 匿名** を有効にする。
2. **Realtime Database → ルール** に、このリポジトリの `database.rules.json` の中身を丸ごと貼り付けて **公開**。
3. **Authentication → 設定 → 承認済みドメイン** に、公開するドメイン（`あなたのユーザー名.github.io`）を追加。

### 別のプロジェクトに変えるとき
**プロジェクトの設定 → マイアプリ → ウェブ** でアプリを登録し、表示される `firebaseConfig` の値（`apiKey`・`authDomain`・`databaseURL`・`projectId`）を `js/firebase-config.js` に書きかえて、上の1〜3をそのプロジェクトでも行ってください。

Firebase がつながらなくても「ひとりで経営」は遊べます（データは端末に保存）。

### データの置き場所
| 場所 | 内容 |
|---|---|
| `tcg/saves/<引き継ぎコード>` | セーブデータ（お店・キャラ・カードのコレクション） |
| `tcg/lb/<プレイヤーID>` | ランキング：`lv`（店レベル）・**`c`（カード図鑑登録数）**・`s`（総売上）・`p`（プレイ時間） |
| `tcg/rooms/<ルームID>` | ルーム（ホストのお店・お客さんの動き・チャット） |

**カード図鑑登録数** は、そのプレイヤーが（自分のどのお店でも）一度でも手に入れたカードの種類数です。売ったり並べたりしても減りません。

## 📁 ファイル構成

```
index.html              入口（three.js は CDN から読み込み）
css/style.css           画面デザイン（カードのホロ・開封演出もここ）
img/mon/*.webp          カードのイラスト（アニモン250種＋色ちがい32種）
js/main.js              起動・画面遷移・メインループ
js/game.js              ゲーム中の操作（補充・開封・カードを置く・ラベル）
js/sim.js               経営シミュレーション（お客さん・臭いと消臭・従業員・レジ・カード販売・手に持つ物・1日の流れ）
js/data.js              商品・ライセンス・設備・従業員・レベルのデータ
js/cards.js             レア度・封入率・パック/BOXの開封・カードの相場
js/carddata.js          全298枚のカードデータ（tools/cards で自動生成）
js/cardart.js           カードの表・裏・パック・BOXの絵（Canvas）
js/cardui.js            カードの画面表示（ホロ・傾き・開封演出）
js/gameui.js            ゲーム中のUI（パソコン・ライセンス・従業員・コレクションファイル・レベル・レジ・建築）
js/render.js            3D描画（棚の商品・並べたカード・倉庫棚のラベル）
js/models/*.js          商品・設備・建物・キャラクターの3Dモデル
js/net.js               Firebase（引き継ぎ・ルーム・チャット・ランキング）
js/save.js              セーブデータ・引き継ぎコード・図鑑の集計
js/firebase-config.js   Firebase の設定
database.rules.json     Realtime Database のルール
tools/cards/            カードデータとイラストを作り直す道具（開発用）
```
