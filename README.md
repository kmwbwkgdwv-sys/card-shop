# 🃏 TCGカードショップシミュレーター

「アニモン（アニマルモンスター）」のトレーディングカードを売るカードショップを経営する、3Dの経営シミュレーションです。
パックを棚に並べて、レジを打って、自分でもパックを開けてレアカードを当てて、シングルカードを売って、お店を大きくしていきます。
ブラウザだけで動くので、GitHub Pages に置くだけでスマホ（横画面）でも PC でも遊べます。最大4人の協力プレイにも対応しています。

> 「TCG Card Shop Simulator」の遊び方と、ポケモンカードのレア度の見た目（ノーマル／ホロ／フルアート／レインボー／ゴールド）を参考にしたオリジナル作品です。公式作品・開発元とは関係ありません。
> お店の基盤は「マートメイツ」、カードに登場するキャラクターは「アニマルモンスター（アニモン）」のものを使っています。

### レア度と見た目（ポケカ風）

| レア度 | 見た目 | 封入率（1枚あたり） | 相場の目安 |
|---|---|---|---|
| **N**（ノーマル） | ふつうの枠。タイプ色の背景と景色の窓 | 69.8% | 5〜10円 |
| **R**（レア） | 絵の窓がホロ（虹色にキラキラ） | 17.35% | 15〜40円 |
| **SR**（スーパーレア） | フルアート。キャラがカード全体に、細かい斜めの凹凸ラインと銀のホロ | 7.6% | 80〜200円台 |
| **SSR**（スペシャルスーパーレア） | **色ちがいのアニモン**×星空のスペシャルアート。銀のグリッター | 4.0% | 300円〜1,000円台 |
| **HR**（ハイパーレア） | SSRをさらに **レインボー** 加工（キャラも背景も虹色） | 1.0% | 1,400〜4,800円 |
| **UR**（ウルトラレア） | SSRをさらに **ゴールド** 加工（金の枠・金色のキャラ・金のグリッター） | 0.25% | 5,000〜16,000円台 |
| ✨ **フラッシュ（箔付き）** | どのレア度にも付く。光の帯が流れて、キラキラと輝く（3Dの棚でも光る） | 各カード 5% | そのカードの **3倍** |

- 封入率は **1枚ごとの独立判定**。1パック5枚それぞれが上の確率で決まります（BOX保証はありません）。
- 1BOX（30パック＝150枚）に入る平均：UR 0.4枚・HR 1.5枚・SSR 6枚・SR 11.4枚・フラッシュ 7.5枚。
- **レアなカードほど高く売れます。** 相場は弾（あとの弾ほど高い）とキャラの人気でも変わり、毎日少しずつ動きます。高いカードを狙うお金持ちのコレクターもたまに来店します。

- 画面でカードにさわる（PCはマウスを動かす）と、カードが傾いて光の反射とホロが動きます。
- カードの絵は Canvas で描いています（`js/cardart.js`）。アニモンのイラストは「アニモン」の3Dモデルから撮影した画像（`img/mon/`）。

## 🧑‍💼 従業員（最大10人）

仕事は **🧾 レジ係** と **📦 品出し係** の2つ。1人ひとりに **得意な仕事** があり、得意でない仕事にすると はやさが60%になります。

| No.3 | Lv.12 | 🐌 遅い | 📦 品出し係 | ¥1,100 |

| No.5 | Lv.20 | 🙂 普通 | 📦 品出し係 | ¥1,500 |
| No.6 | Lv.25 | 🙂 普通 | 🧾 レジ係 | ¥1,500 |
| No.7 | Lv.30 | ⚡ とても早い | 🧾 レジ係 | ¥2,800 |
| No.8 | Lv.36 | 🏃 早い | 📦 品出し係 | ¥2,100 |
| No.9 | Lv.43 | 🏃 早い | 🧾 レジ係 | ¥2,100 |
| No.10 | Lv.50 | ⚡ とても早い | 📦 品出し係 | ¥2,800 |

**品出し係の仕事**（基本はスーパーマーケットシミュレーターと同じ）
1. 値札のついた棚の在庫が減っていたら、倉庫棚や店の前の段ボールから補充する
2. 発注して店の前に届いた段ボールを持って、**その商品のラベルが貼ってある倉庫棚の段** にしまう（ラベルのない商品は片付けない。頭の上に 🏷️❓ が出ます）
3. 空になった段ボールはゴミ箱へ

倉庫棚の段を狙って「ラベルを貼る」で商品を選べます（プレイヤーはどの段にも置けて、ラベルのない段に置くと自動でその商品のラベルが貼られます）。

| | スマホ | PC |

**基本の流れ**：パソコン室（入口の右・倉庫から入る）のマネージャーボードでパックを発注 → 店の前に届いた段ボールを持って「開ける」→ 棚を狙って「補充」→ 入口の看板を OPEN → レジでスキャン＆お会計 → 閉店して収支画面 →「次の日へ」。
パックの段ボールを持っているときに「🎴 パックを開封」でカードが手に入るので、カードテーブルに並べてシングルとしても売れます。

## 🚀 GitHub Pages で公開する

1. GitHub で新しいリポジトリ（例：`tcg-card-shop-simulator`）を **Public** で作成。
2. このフォルダの中身（`index.html` / `css` / `js` / `img` / `icons` / `README.md` など）を **フォルダごと** アップロードして Commit。
   - `index.html` がリポジトリの一番上にある状態にしてください。
3. **Settings → Pages** で **Source: Deploy from a branch**、**Branch: main / (root)** を選んで Save。
4. 1〜2分後に `https://あなたのユーザー名.github.io/リポジトリ名/` で遊べます。

ビルド不要の素の JavaScript（ES モジュール）です。three.js と Firebase は CDN から読み込みます。
ローカルで試すときは `python3 -m http.server` などでフォルダを配信して `http://localhost:8000` を開いてください（ファイルを直接開くと動きません）。

## 🔥 Firebase の設定（オンライン機能）

`js/firebase-config.js` には **マートメイツと同じ Firebase プロジェクト（supermarket-9acfb）** を設定してあります。
このゲームのデータはデータベースの **`tcg/` の下** に保存されるので、マートメイツのデータとは混ざりません。

### A. マートメイツと同じプロジェクトを使う（かんたん）
1. Firebase コンソール → **Realtime Database → ルール** に、このリポジトリの `database.rules.json` の中身を丸ごと貼り付けて **公開**。
   （マートメイツ用のルール `saves`・`lb`・`rooms`・`shops` もそのまま入っているので、マートメイツも今までどおり動きます）
2. 別のドメインで公開する場合は **Authentication → 設定 → 承認済みドメイン** に追加（同じ `ユーザー名.github.io` なら追加ずみ）。

### B. 新しいプロジェクトを使う
1. Firebase コンソールでプロジェクトを作成。
2. **Authentication → Sign-in method → 匿名** を有効にする。
3. **Realtime Database** を作成し、ルールに `database.rules.json` を貼り付けて公開（`tcg` の部分だけでもOK）。
4. **プロジェクトの設定 → マイアプリ → ウェブ** でアプリを登録し、`firebaseConfig` の値を `js/firebase-config.js` に書きかえる（`databaseURL` を必ず入れる）。
5. **Authentication → 設定 → 承認済みドメイン** に `あなたのユーザー名.github.io` を追加。

Firebase がつながらなくても「ひとりで経営」は遊べます（データは端末に保存）。

### データの置き場所
| 場所 | 内容 |
|---|---|
| `tcg/saves/<引き継ぎコード>` | セーブデータ（お店・キャラ・カードのコレクション） |
| `tcg/lb/<プレイヤーID>` | ランキング：`lv`（店レベル）・**`c`（カード図鑑登録数）**・`s`（総売上）・`p`（プレイ時間） |
| `tcg/rooms/<ルームID>` | ルーム（ホストのお店・お客さんの動き・チャット） |

**カード図鑑登録数** は、そのプレイヤーが（自分のどのお店でも）一度でも手に入れたカードの種類数です。売ったり並べたりしても減りません。
